WADA SANZO — проверенная версия
Источник цветовых данных:
https://github.com/mattdesl/dictionary-of-colour-combinations

В наборе 348 исторических комбинаций с HEX/RGB/LAB.
Приложение загружает эти данные напрямую из открытого набора.
Избранное хранится в localStorage на устройстве.
Новая выбранная комбинация автоматически становится первой в разделе ИЗБРАННОЕ.

Установка на iPhone:
1. Разместить файлы на HTTPS.
2. Открыть index.html в Safari.
3. Поделиться → На экран «Домой».
